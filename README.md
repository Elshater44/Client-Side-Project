# E-Commerce Website

A modern e-commerce website built with HTML, CSS, and JavaScript.

## Project Structure

```
├── assets/
│   └── index-page/
│       └── partners-logo/
├── css/
│   ├── cart.css
│   ├── checkout.css
│   ├── favorite.css
│   ├── footer.css
│   ├── global.css
│   ├── hero.css
│   ├── index.css
│   ├── navbar.css
│   └── products.css
├── html/
│   ├── cart.html
│   ├── checkout.html
│   ├── favorite.html
│   ├── index.html
│   └── products.html
└── js/
    ├── cart.js
    ├── checkout.js
    ├── favorite.js
    ├── global.js
    ├── index.js
    └── products.js
```

## Features

-   Product browsing and listing
-   Shopping cart functionality
-   Checkout process
-   Favorites/Wishlist management
-   Responsive navigation
-   Global styling for consistent UI
-   Partner logos showcase

## Pages

-   **Home (`index.html`)**: Landing page with hero section and partner logos
-   **Products (`products.html`)**: Product listing and browsing
-   **Cart (`cart.html`)**: Shopping cart management
-   **Checkout (`checkout.html`)**: Order processing and payment
-   **Favorites (`favorite.html`)**: Saved/wishlisted items

## Technologies Used

-   HTML5
-   CSS3
-   JavaScript (Vanilla)

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/ElshaterITI/Client-Side-Project.git
```

2. Open `html/index.html` in your web browser to view the website.

## Development

-   CSS styles are organized by component/page in the `css` directory
-   JavaScript functionality is split into modules in the `js` directory
-   Assets and images are stored in the `assets` directory
